# بوابة الاستعلام عن نتائج الطلاب

موقع كامل (باك اند + فرونت اند) بيدي كل طالب نتيجته باستخدام "كود الطالب" بتاعه فقط.

## محتويات المشروع

- `server.js` — السيرفر (Node.js / Express). هو اللي بيقرأ بيانات الطلاب وبيرجّع نتيجة الطالب المطلوب فقط عن طريق `/api/result`.
- `data/students.json` — بيانات الطلاب (تم استخراجها من ملف الإكسل اللي بعتّه). **الملف ده لازم يفضل سري ومحدش يوصله غير السيرفر نفسه.**
- `public/index.html` — واجهة الموقع اللي الطالب بيشوفها ويدخل بيها الكود.
- `package.json` — قائمة المكتبات المطلوبة لتشغيل السيرفر.

## أهم نقطة أمان

كل بيانات الطلاب موجودة على السيرفر بس، مش في صفحة الموقع نفسها. يعني لو حد فتح "عرض مصدر الصفحة" (View Source) مش هيقدر يشوف بيانات أي طالب تاني — هيوصله بس نتيجة الكود اللي هو بعته، وده أهم فرق بين الحل ده وبين أي حل يعتمد على ملف بيانات جوه الصفحة نفسها.

## إزاي تنشر الموقع مجانًا (خطوة بخطوة) — استضافة Render

1. اعمل حساب مجاني على [render.com](https://render.com) (تقدر تسجل بحساب GitHub أو بالإيميل).
2. لو معندكش حساب GitHub، اعمل واحد مجانًا على [github.com](https://github.com)، وبعدين اعمل "New repository" وارفع فيه كل ملفات المشروع ده (فيه زرار "Upload files" في صفحة الريبو، تقدر تسحب المجلد كله عليه من غير ما تستخدم أي أوامر).
3. ارجع لـ Render واختار **New → Web Service**.
4. اربطه بحساب GitHub بتاعك واختار الريبو اللي رفعته.
5. في إعدادات الخدمة:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. دوس **Create Web Service** واستنى دقيقة لغاية ما يخلص البناء.
7. هيديك لينك زي `https://your-app-name.onrender.com` — ده لينك موقعك الفعلي، شاركه مع الطلاب.

> ملحوظة: الخطة المجانية في Render بتنام لو محدش استخدمها لمدة، وأول طلب بعد النوم بياخد شوية ثواني إضافية لحد ما يصحى، وده طبيعي في الخطط المجانية.

### بديل أسهل شوية: Glitch.com

لو عايز تتجنب موضوع GitHub خالص:
1. روح [glitch.com](https://glitch.com) واعمل حساب مجاني.
2. اعمل مشروع جديد فاضي (Node.js)، وبعدين ارفع/الصق ملفات المشروع ده مكان ملفاته.
3. المشروع بيبقى لايف فورًا بلينك زي `https://your-project.glitch.me`.

## تشغيل المشروع على جهازك للتجربة (اختياري)

لو حابب تجرب الموقع على جهازك قبل ما ترفعه:

```
npm install
npm start
```

وبعدين افتح المتصفح على `http://localhost:3000`

## حاجات محتاج تعدّلها بنفسك

- في `public/index.html` فيه سطر مكتوب عليه "اسم المعهد / الكلية هنا" — غيّره لاسم مؤسستك الحقيقي.
- لو عايز تضيف شعار حقيقي بدل الختم البسيط اللي في أعلى الصفحة، استبدل كود الـ `<svg class="seal">` بصورة الشعار.

## بخصوص منع تصوير الشاشة

زي ما اتفقنا، مفيش موقع يقدر يمنع السكرين شوت 100% لأن أي حد يقدر يصور الشاشة بموبايل تاني. اللي عملته:

- منع تحديد/نسخ النص، ومنع الـ right-click، ومنع الطباعة.
- تغطية الشاشة تلقائيًا لو الطالب بدّل التبويب (زي وقت فتح أداة تصوير الشاشة).
- **علامة مائية (Watermark)** شفافة فوق النتيجة فيها كود الطالب ووقت الفتح — دي أقوى وسيلة فعلية، لأن لو حد صوّر النتيجة وسابها تتشارك، هيبقى واضح مين اللي صورها ومتى.
